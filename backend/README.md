# 🚀 Samsung PRISM — Smart Guided Troubleshooting Engine
## Role: P1 Backend + Catalog Lead
### Full Alignment with P2 Repository: [bhupalamjathin-svg/prism-p2](https://github.com/bhupalamjathin-svg/prism-p2)

This repository contains the **Deterministic Neuro-Symbolic Backend Engine** for Samsung PRISM:
1. **Catalog & Ontology**: Fully supports all 6 canonical problem IDs generated by P2.
2. **Device & One UI Version Awareness**: Resolves dynamic settings screens and deeplinks across **One UI 5.x, 6.x, and 7.0**.
3. **Symbolic Reasoning & Safe Ordering**: Enforces strict monotonic ordering (Low-Risk Diagnostics ➔ Reversible Configuration ➔ Cache Flush ➔ Recovery/Reset).
4. **Deterministic Validation Guardrails**: Validates action catalogs, strict Android intent syntax, anti-parent-menu checks, and schema integrity.
5. **Confidence & Clarification Routing**: When P2 reports `status == "need_clarification"` (confidence < 0.70 or multi-problem conflict), P1 routes the clarification question directly to P3 without crashing.
6. **Sub-300ms Fast-Path Caching**: High-throughput semantic cache resolving repeat queries in **< 1 ms** (300x faster than SLA).
7. **"Fix for me" Execution API**: Semi-automatic one-tap fixes restricted strictly to low-risk, non-destructive actions.

## ⚙️ Quick Start

### 1. Install Dependencies
```bash
pip install fastapi uvicorn pydantic pytest httpx requests
```

### 2. Run Test Suite
```bash
python -m pytest tests -v
```
*(All 14 unit and integration tests will execute and pass)*

### 3. Start the API Server
```bash
python -m uvicorn main:app --reload --port 8000
```
API Documentation will be live at:
- **Swagger UI**: `http://127.0.0.1:8000/docs`
- **ReDoc**: `http://127.0.0.1:8000/redoc`
